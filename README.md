# Hashem Chess Puzzle

تطبيق تدريب شطرنج من أكاديمية Hashem Chess Castle: دروس تفاعلية، أكثر من 17 ألف لغز مقسمة بالموضوع والمستوى، لعب ضد الكمبيوتر، وتحليل بمحرك Stockfish 19.

A chess training app by the Hashem Chess Castle academy: interactive lessons, over 17,000 puzzles by theme and level, play against the computer, and analysis with Stockfish 19.

## Source code

The complete source code of each released version is in **HashemChessPuzzle-android.zip** in this repository (Android Studio project, web app sources, build and import tools). See README.md inside the archive to build it.
